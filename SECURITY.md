# Security Policy

## Supported versions

The latest `0.1.x` release line receives security fixes. This is alpha software
for a local, single-trusted-host boundary; it is not a hosted multitenant
security perimeter.

## Reporting a vulnerability

Use the repository's **Security** tab to submit a private vulnerability report.
Do not open a public issue for a suspected vulnerability and do not attach real
memory databases, credentials, access tokens, private transcripts, or personal
data.

Include the affected version, a minimal synthetic reproduction, expected impact,
and any suggested mitigation. Maintainers will acknowledge a complete report
when it is reviewed; response times are not guaranteed during the alpha stage.

For deployment assumptions and non-goals, read
[docs/LOCAL_SECURITY.md](docs/LOCAL_SECURITY.md).
